# margin

A design system for Marius Busen's personal site: essays, poems and small projects. Paper and ink, lots of room, and a few small delights in the margins.

Open `index.html` for the living style guide. `dist/` has every page as one self-contained file.

## Files

| file | what it is |
|---|---|
| `tokens.css` | every value: colour, type, space, shape, motion. light and dark. |
| `tokens.json` | the same tokens as JSON, generated by `build.py` |
| `fonts.css` + `fonts/` | Fraunces, Inter, IBM Plex Mono, self-hosted (OFL) |
| `base.css` | reset, page, type roles, essay prose, poems |
| `components.css` | nav, footer, buttons, tags, index lists, cards, figures, sidenotes, quotes, stats, fields, marks, characters, toast, tooltip, hover preview, reveal, clock |
| `margin.js` | behaviour, no dependencies: theme toggle, scroll reveal, sidenotes on mobile, hover preview, filters, clock, toast, copy, characters |
| `index.html` | the style guide |
| `templates/` | home, writing (index), essay, poem, project |
| `build.py` | writes `tokens.json` and bundles each page into `dist/` |
| `SKILL.md` | instructions for Claude to apply the system |

## Use it

```html
<head>
  <!-- set the saved theme before paint, so there is no flash -->
  <script>try{var t=localStorage.getItem("m-theme");if(t)document.documentElement.dataset.theme=t}catch(e){}</script>
  <link rel="stylesheet" href="margin/fonts.css">
  <link rel="stylesheet" href="margin/tokens.css">
  <link rel="stylesheet" href="margin/base.css">
  <link rel="stylesheet" href="margin/components.css">
</head>
<body class="m-grain">
  <div class="m-page"> … </div>
  <script src="margin/margin.js"></script>
</body>
```

For a one-off file, write the page next to the others and run `python3 build.py`. For a different project, copy the folder.

## Principles

1. **Paper, not screen.** Warm surfaces, a little grain, ink instead of black.
2. **Words first.** Type does the work. Images and colour serve the text.
3. **One accent, rarely.** Terracotta marks what matters: a link, a number, a note.
4. **Delight at the margin.** A hand-drawn underline, a tilt, a spring. Small, optional, never in the way of reading. One mark per screen.
5. **Calm motion.** Things ease out and settle. Everything respects `prefers-reduced-motion`.

## Type

| role | class | font | size (mobile → desktop) |
|---|---|---|---|
| hero | `m-hero` | Fraunces 360 | 51 → 118 px |
| display | `m-display` | Fraunces 380 | 42 → 83 px |
| h1 / h2 / h3 | `h1` `h2` `h3` | Fraunces 400–450 | 34→59 · 27→42 · 22→30 px |
| lead | `m-lead` | Fraunces 400 | 19 → 23 px |
| essay body | `m-prose` | Fraunces 400, old-style numerals, 34em measure | 19 → 23 px |
| poem | `m-poem` | Fraunces 400, line height 1.75, hanging lines | 19 → 23 px |
| ui body | body | Inter 400 | 16 → 18 px |
| caption | `m-caption` | Inter 400 | 13.5 → 14.4 px |
| meta / eyebrow | `m-meta` `m-eyebrow` | IBM Plex Mono 400/500 | 12 px |

Everything is lowercase in headings and UI copy, as in the essays. Poems keep their own capitalisation.

## Colour

Paper and ink carry almost every page. Earth hues are for marks, charts and illustration.

- **Light:** `--bg` paper-100 `#f3ede3`, `--surface` paper-50 `#fbf8f3`, `--text` ink-900 `#2a241d`, `--accent` terracotta `#c4512b`.
- **Dark:** `--bg` night-800 `#1b1814`, `--surface` night-700 `#24201b`, `--text` moon-100 `#f1eadf`, `--accent` `#d6612f`.
- **Text contrast on paper-100:** text 13.2:1 · text-2 6.3:1 · text-3 4.7:1 · accent-text 4.9:1. `ink-500` fails as text; use it for rules and axes only.
- **Data:** `--data-1…3` (lake, terracotta, pine) pass every colour-vision-deficiency check in any combination, in both modes. `--data-pos` / `--data-neg` (ochre, dusk) are a diverging pair. Charts with more than three series fold into "other". Chart chrome uses `--chart-grid` and `--chart-axis`; soft fills use `--tint-1`, `--tint-pos`, `--tint-neg`.
- Components use **semantic roles** only (`--bg`, `--text-2`, `--accent` …), never primitives. Dark mode follows the system setting; `data-theme="light|dark"` on `<html>` overrides it.

## Components, at a glance

- `m-nav` with `m-wordmark` · `m-footer` with `m-signoff`
- `m-btn` (`is-primary`, `is-ghost`) · `m-tag` (`is-on`) · `m-seg` · `m-kbd`
- `m-index`: a list of works (year, title, kind, arrow). Add `is-dimming` to fade siblings on hover; add `data-preview="sun|clay|sage|dusk|sky"` or `data-preview-src="img.jpg"` to links for a floating preview.
- `m-card` (`is-link`, `is-sunk`) · `m-deck` (a card on a stack)
- `m-figure` (`is-print`, `is-tape`, `--tilt`) · `m-ph` placeholders with `data-tone` until real photos exist
- `m-with-margin` + `m-sn-ref` + `m-sidenote`: notes in the margin on wide screens, tap to open on small ones
- `m-pullquote` · `m-quote` · `m-stat` · `m-dropcap` · `m-math` / `m-math-block`
- `m-field`, `m-input` (`is-line`), `m-textarea` (`is-lined`), `m-check`
- marks: `m-mark-under`, `m-mark-loop`, `m-mark-swash` (draw on scroll; add `is-static` to show at once), `m-asterism`, and `<hr>` inside prose becomes a squiggle
- characters: `<span data-art="hanni|nanni|star|end">`
- `m-theme` + `data-theme-toggle` · `m-clock` · `m-tip` · `Margin.toast("…")` · `m-reveal` (+ `data-stagger` on the parent)
